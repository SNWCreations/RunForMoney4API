# RunForMoney4API

The application programming interface provided by the RunForMoney4 mod.

To start using it, see `snw.mods.rfm.api.platform.PlatformInstance` and
 events defined in `snw.mods.rfm.api.event` package.

The API in this project is NOT guaranteed to be stable, they will be
 changed without notice in further version. Due to this, avoid using
 the dynamic `SNAPSHOT` key as version when linking to this API.

To get pre-built artifacts of this project, use [JitPack](https://jitpack.io),
 for usage, see [their tutorial](https://docs.jitpack.io/intro/#building-with-jitpack).
Use exact commit SHA as version to ensure your project will not break
 when I commit changes to this repository. I will avoid force-pushing
 unless there is security issues (e.g. credentials leak).
